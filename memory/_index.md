## Multi-Phase Convention

When a new product phase begins:
- **Existing domain files**: append a `## Phase N Additions` section — do not create a duplicate file
- **New domains**: create `memory/<new-domain>.md` with a `> Introduced in Phase N.` note in the header, and add it to this index
- See `memory/AGENTS.md` for the full multi-phase memory protocol
